## 구현

- 기본 모니터 `workArea` 크기의 별도 투명·frameless BrowserWindow 한 개를 생성한다.
- 팔레트는 `skipTaskbar: true`, `alwaysOnTop: false`, 별도 sandboxed session과 최소 preload를 사용한다.
- Workspace 시작 자동 표시는 UX-07D 전까지 유지한다.
- 기존 TD2 version 1, 12열 geometry, 13개 widget ID와 `x/y/w/h/visible`을 읽기 전용으로 투영한다. 저장·마이그레이션·ID 재발급은 없다.
- 기존 컴포넌트와 로컬 일정·업무·메모 owner를 재사용한다. Finance, SCHOOL, AI, 파일 및 raw IPC는 팔레트 preload에 노출하지 않는다.
- renderer가 실제 widget hit region을 제한된 IPC로 전달하고 main이 Windows cursor 위치를 판정한다. 위젯 영역만 interactive이며 gap은 click-through다. 편집/drag/resize는 UX-07C view mode에서 추가하지 않았다.
- 트레이에 Desktop 위젯 표시/숨기기 명령을 추가했다. Workspace와 팔레트의 show/hide 수명은 독립이며 명시적 완전 종료 때만 함께 파기된다.
- 기존 Dock은 변경하거나 복제하지 않았다.

## UX-07C-R1/R2 안전 검증 결과

- 위젯 직접 클릭, 실제 작업 표시줄 항목 제외, 실제 Alt+Tab 제외는 모두 `NOT RUN`으로 남았다.

- 사용자가 정상 종료를 승인한 뒤 운영 보건 앱은 자체 미저장 경고를 통해 정상 종료됐다. 저장·복구·데이터 편집·강제 종료는 수행하지 않았다.
- 이후 일반 앱 창은 종료됐지만 정상 사용자 프로필을 사용하는 기존 BOGUNON 백그라운드 서비스가 남아 있었다. 새 R2 실행이 해당 인스턴스 또는 프로필과 섞일 가능성이 있어 즉시 중단했다.
- R2에서 생성한 QA 프로세스만 종료했으며 기존 BOGUNON 서비스와 운영 프로필은 변경하지 않았다.
- 최초 UX-07C 검증 중 gap click이 당시 열려 있던 운영 보건 앱에 전달되어 선택 상태가 바뀌었을 가능성이 있었다. 저장은 실행되지 않았고 이후 해당 상태를 조회·복구·수정하지 않았다. 후속 검증은 합성 target만 사용했다.
