## Scope

The existing widget library presents all 13 widgets in basic/schedule/work groups
as horizontal icon/copy/switch cards. Existing DESIGN-07 tokens provide rose ON
and neutral OFF surfaces. Container widths select three, two or one columns.
The existing visibility transform retains saved geometry on restore. The Electron
Grid adapter persists explicit drag/resize completion, not automatic compaction.

Widget IDs, saved schema, memo data, UX-09 toolbox and Newsletter routing remain
intact. No authentication, Main/preload/IPC, engine, dependency or lockfile changes
are included. The drawer and visibility transform are shared frontend seams;
new visual CSS and the Grid adapter are scoped to the Electron candidate.

### Windows symlink precondition

The ordinary token could not create file symlinks: Node returned EPERM and native
`CreateSymbolicLinkW`, even with the unprivileged flag, returned error 1314.
E: is NTFS; regular writes, hardlinks and directory junctions worked. Fresh absent
link paths excluded a collision. The token lacked `SeCreateSymbolicLinkPrivilege`;
Developer Mode was not enabled through this work.

The user explicitly opened and confirmed a QA-only administrator PowerShell, then
pasted the reviewed commands. Only the targeted 14 tests and, after their success,
the full regression were run there. All 14 became green without source changes.
The targeted filter excluded the other 148 tests in those files; it did not add
skip annotations. The subsequent unfiltered full run passed all runnable tests.
No install, Git, product build, persistent environment changes, Developer Mode or
security-policy modifications were performed in that terminal. Codex, type checks,
build and Git operations remained non-elevated. This does not imply that the
ordinary token now has symlink-creation permission.

## Reproduction and evidence locations

Use an independent dependency/build environment. Prepare fixtures and build assets
under normal privilege before testing; `prepare-tests.mjs` alone does not create
the OCR runtime/renderer boundary generated by the Electron build.

```text
node scripts/electron-p0/prepare-tests.mjs
npm run electron:p0:build
node node_modules/vitest/vitest.mjs run electron-p0/tests src/dashboard src/dock --no-file-parallelism --maxWorkers=1 --no-cache
node node_modules/typescript/bin/tsc -p electron-p0/tsconfig.json --noEmit
node node_modules/typescript/bin/tsc -p electron-p0/tsconfig.renderer.json --noEmit
node node_modules/typescript/bin/tsc -p electron-p0/tsconfig.tests.json --noEmit
```

The test command requires a Windows token permitted to create the real symlink
fixtures. Obtain explicit authorization for a QA-only elevated terminal if needed;
do not skip those tests or replace file symlinks with hardlinks/junctions.
