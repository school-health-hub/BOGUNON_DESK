## 구현

- `P0App`의 기존 `newsletterOpen`·`newsletterLoaded`를 유일한 수명주기 owner로 유지했다.
- Registry의 `documents-education` / `newsletter` 매핑을 그대로 사용한다.
- Newsletter를 App Shell persistent workspace 안으로 옮겼다. 최초 진입 후에는 숨김·`inert` 상태로 유지되며 다른 카테고리에서 재진입해도 같은 `NewsletterStudio` 인스턴스를 다시 표시한다.
- Rail 이동은 `NewsletterStudio`의 기존 `busy`·`projectBusy` 정책을 통과해야 한다. 생성·파일 작업 또는 프로젝트 작업 중에는 이동 요청을 거부하고 Newsletter 화면·원고·Rail 선택을 유지하며, 작업이 끝난 뒤 새 이동 요청만 허용한다.
- 현재 위치는 `문서·교육자료 / 보건소식지 제작소`로 표시한다.
- `보건 업무로` 동작은 기존 확인창을 추가하지 않고 `문서·교육자료` 목록으로 돌아간다.
- Home은 계속 마운트되며 Newsletter와 동시에 보이지 않는다.
- App Shell 안에서 전체 viewport 높이를 중복 요구하지 않도록 Newsletter 전용 범위의 높이·스크롤 CSS만 조정했다.
