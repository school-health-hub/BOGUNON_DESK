# C — 설정 → 화면 배치 시안

## 교사용 문구와 흐름

`설정 > 화면 > 화면 배치`에 다음을 둔다.

1. **사용 방식** — `한 화면에서 함께 사용` / `두 화면으로 나누어 사용`
2. **연결된 화면** — 번호, 주 화면 여부, 해상도, 배율, `화면 식별`
3. **보드를 표시할 화면** — 2대 프리셋에서 단일 선택
4. **바탕화면 아이콘 안전 영역** — `20% / 22% 권장 / 25% / 직접 입력`
5. **미리보기** — 일반 화면과 보드 화면의 축소 미리보기. “Windows 화면 배치를 바꾸지 않습니다.” 고정 안내
6. **행동** — `적용`, `취소`, `기본값 복원`

적용 전에는 draft만 바뀐다. `적용`은 검증 후 atomic 저장, `취소`는 편집 체크포인트 복원, `기본값 복원`은 연결 상태에 맞는 추천안을 draft에만 넣는다. OS 주/보조 지정, 해상도, 배율, 아이콘 위치는 바꾸지 않는다.

첫 실행에서는 연결된 화면 수를 감지해 추천안을 설명하고 사용자가 선택해야 적용한다. 1대는 안전 영역 22%, 2대는 비주 화면을 보드 후보로 제안하되 자동 확정하지 않는다.
