# A — 단일 모니터 현행/개선 비교

## 현행 캡처 판독

| 영역 | 관찰 | 영향 |
|---|---|---|
| 좌측 | 아이콘 3열이 시계, 월간 일정, 급식과 교차한다 | 아이콘/위젯 모두 읽기와 클릭 목표가 불명확하다 |
| 상단 | 시계와 오늘의 보건실이 서로 떨어진 별도 카드다 | 하루 시작 정보가 한 번에 스캔되지 않는다 |
| 중앙 | 월간 일정이 폭 64%가량을 차지하나 바탕화면 아이콘이 비쳐 혼잡하다 | 달력 셀과 파일명이 경쟁한다 |
| 우측 | 빠른 메모와 알림은 정렬됐으나 나머지 보드와 기준선이 다르다 | 독립 창의 모음처럼 보인다 |
| 하단 | 급식은 좌측 아이콘 위에 있고 Dock은 중앙에 안정적으로 떠 있다 | 급식은 침범, Dock은 보존 가치가 높다 |

## 개선안: 안전 영역 + 우측 정렬 Bento 보드

- Windows 아이콘을 이동하지 않고 좌측 **20–25% 안전 영역**을 비운다. 기본 22%, 사용자가 20/22/25% 또는 직접값을 선택한다.
- 보드는 나머지 work area에 우측 정렬한다. 상단은 `시계·날짜 | 오늘의 보건실 | 메모 | 알림`, 중앙은 `월간 일정(2/3) | 오늘 핵심 업무(1/3)`, 하단은 `급식 | 날씨·D-Day·보조 정보`, Dock은 화면 하단 중앙에 유지한다.
- 정보 유리, 작업 시트, 개인 메모 재질을 구분하되 공통 radius/border/shadow 토큰을 쓴다. 크림 화이트 바탕, 로즈 포커스, 민트 상태색, 네이비 본문으로 한글 대비를 확보한다.
- 공식 로고는 Settings/Workspace 헤더에서만 사용하며 위젯 장식으로 반복하지 않는다.
- Dock=실행, Palette=정보 확인/빠른 명령, Desktop Surface=바탕화면 배치, Workspace=편집, Settings=환경설정의 역할을 유지한다.
- 작은 창(폭 ≤820 또는 유효 높이 ≤680)은 단일 열이다. 시계/보건실은 유지하고, 메모·알림·급식·보조 정보는 접을 수 있으며 월간 일정은 내부 스크롤/주간 요약으로 전환한다.

시안은 [mockup-single.svg](mockup-single.svg)에 있다. 배경 아이콘은 회색 안전 영역 표식으로만 나타내며 Explorer를 조작하는 기능이 아니다.
