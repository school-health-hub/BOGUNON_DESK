# B — 듀얼 모니터 현행/개선 비교

## 목표 배치

| 화면 | 기본 역할 | 구성 |
|---|---|---|
| 일반 Windows 화면 | 파일·업무 앱 사용 | 아이콘과 일반 창을 그대로 보존. Palette/Dock만 사용자가 선택한 경우 표시 |
| 보드 화면 | 상시 보건업무 정보 | 상단 오늘 정보, 중앙 달력·핵심업무, 우측 메모·알림, 하단 급식·보조정보 |

1대 프리셋은 같은 화면의 좌측 안전 영역을 지키고, 2대 프리셋은 사용자가 선택한 보드 대상에 전체 보드 폭을 제공한다. “주 모니터”와 “보드 모니터”를 동일시하지 않는다.

## 선택과 혼합 DPI

- 연결 모니터 목록은 `1 · 주 화면 · 1920×1080 · 100%`, `2 · 1600×900 · 125%`처럼 교사가 식별 가능한 문구로 표시한다.
- `식별`은 각 화면에 1/2 번호를 잠깐 보여주는 앱 내부 표시다. Windows 디스플레이 설정을 변경하지 않는다.
- 기하 저장은 논리 DIP와 정규화 비율을 함께 기록하고, 실제 픽셀은 매번 현재 `scaleFactor`로 투영한다.
- 창 이동/재연결/DPI 변경 때 `workArea`를 다시 읽어 title/control이 보이는 범위로 임시 투영한다. 임시 투영은 저장 원본을 덮지 않는다.
- Dock은 하나만 존재한다. 선택한 화면이 사라지면 연결된 화면으로 임시 이동하되 저장된 선호 대상은 유지한다.
- 3대 이상은 자동 분산하지 않는다. 기존 명시 선택을 보존하고 새 모니터 프로필은 빈 상태로 시작한다.
