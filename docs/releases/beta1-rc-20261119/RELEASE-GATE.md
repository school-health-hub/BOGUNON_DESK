공식·학교 배포: 승인 보류. GitHub Release, main 병합, 공개 배포는 수행하지 않는다.

제품 기준 d03a58fa7f73411aa2cdb9ebd31c0d8527e21947 및 RC-METADATA.json의 두 바이너리만 대상으로 한다.
이번 단계는 기존 검증 통합과 복사본 무결성 검사이며 제품 테스트·빌드·설치·인증을 반복하지 않았다.

## 완료 근거
- Portable 실제 실행, 주요 로컬 기능: 직접 검증과 동일 코드 근거 재사용을 QA-SUMMARY.md에서 구분.
- Supabase 실제 로그인·세션·로그아웃, ChatGPT 인증·모델 조회: 각 원본 보고서에 한정.
- Native 파일창13 PASS, NSIS 정적 검사 및 집 PC 실제 설치·제거·재설치: 기존 실행 증거 확인.
- 사용자 자료1796파일 해시 불변은 해당 기존 목록 범위.
- 복사한 EXE2개는 원본과 승인 SHA 일치. 제품 코드·설치 상태 변경 없음.
- QA 도구는 별도 원격 브랜치에 보존. RC Git 변경은 검증 문서만 포함.

## 승인 전 결정
1. 미서명 설치본 배포 정책과 서명 필요 여부를 책임자가 결정한다.
2. 학교 PC 환경 검증 및 배포 대상 범위를 정한다.
3. AI 생성 기능의 비용·권한·검증 계획을 정한다. 현재 생성 기능 완료 주장은 금지한다.
4. 알려진 이슈의 수용·보완 담당자와 범위를 기록한다.

## 원격 보존과 인계 제한
문서는 독립 RC 문서 브랜치로 보존한다. 바이너리·원본 실행 로그·스크린샷·인증 프로필은 Git에 포함하지 않는다.
EXE와 원본 증거는 현재 E:에 있다. 문서 원격 동기화는 다른 PC에서 바이너리와 전체 증거를 복원할 수 있다는 뜻이 아니다.
원격 전용 전체 인계 판정은 PARTIAL이며, 해당 로컬 파일이 필요한 재개 단계는 승인된 온라인 전송과 해시 검증 전까지 BLOCKED다.
학교 PC와 다른 Windows 환경을 검증했다고 주장하지 않는다.
