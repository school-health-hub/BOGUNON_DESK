# 설치 안내 — 내부 테스트용 beta.1
Windows x64 / BOGUNON DESK 2.0.0-beta.1. 설치본은 미서명이며 공개 배포 승인을 받지 않았다.

## 파일 확인
파일명과 SHA-256은 [SHA256SUMS.txt](SHA256SUMS.txt)에 있다. PowerShell의 Get-FileHash -Algorithm SHA256으로 사용 전 대조한다. 해시가 다르면 실행하지 않는다.
Portable과 NSIS는 서로 다른 파일이며 기존 INT-07 파일과 동일한 해시라고 주장하지 않는다.

## 설치·실행
일반 사용자 단위 NSIS 설치다. 설치 전 작업을 저장하고 기존 BOGUNON DESK를 정상 종료한다. 예상 밖의 관리자 권한 요구나 사용자 데이터 삭제 안내가 나오면 중단한다.
현재 실제 검증 경로는 E:\BOGUNON_DEV\installed-beta1-qa-20261119 이다. 기본 경로를 포함한 다른 경로 전체가 검증된 것은 아니다.
현재 이 경로의 최종 재설치 상태를 유지하며 QA 앱은 정상 종료되어 있다. 이 문서 정리 과정에서는 설치나 재실행을 하지 않는다.
Portable은 설치 방식과 별개로 사용한다. 두 버전을 동시에 실행하지 않는다.
SmartScreen·학교 정책이 차단하면 담당자에게 확인하며 보안 기능을 끄거나 관리자 권한으로 우회하지 않는다.

## 제거와 사용자 데이터
Windows에 등록된 BOGUNON DESK 제거 항목을 사용한다. 다른 프로그램의 제거 항목을 조작하지 않는다.
사용자 데이터는 보존하는 정책이다. 사용자 자료를 먼저 백업하고, 앱 데이터 삭제 옵션을 선택하거나 프로필 폴더를 수동 삭제하지 않는다.
실제 집 PC QA에서는 제거 후 합성 자료 및 기존 자료 해시 보존, 같은 버전 재설치 후 복원을 확인했다. 모든 버전 간 업그레이드를 검증한 것은 아니다.
Windows 계정에 묶인 인증·암호화 상태를 다른 PC에 그대로 복사하거나 자동 이관하지 않는다. RC에는 인증 프로필과 실제 사용자 자료가 없다.

## 연결·AI 기능
로컬 업무 기능과 인터넷 필요 기능은 구분한다. Supabase 로그인과 ChatGPT 연결은 별도 인증이다.
실제 로그인·세션 복원·로그아웃 및 ChatGPT 인증·모델 조회는 기존 근거 범위에서 확인했다.
AI 생성은 NOT RUN이다. 가격·사용량·잔여 한도 및 모델 접근 권한이 확인되기 전 생성 요청을 보내지 않는다. 모델 조회 성공이 무료 생성이나 모든 AI 기능 성공을 뜻하지 않는다.
학교 PC의 프록시·보안 정책·브라우저 인증 복귀는 별도 검증한다.

## 자원과 지원 범위
관측한 디스크 여유는 해당 QA 시점 값이며 설치 최소 사양 보증이 아니다. 공간 부족·쓰기 오류 발생 시 중단한다.
검증된 범위와 제외 항목은 QA-SUMMARY.md 및 KNOWN-ISSUES.md를 확인한다.
