Electron 제품 빌드와 TypeScript는 PASS. 스타일·Palette 집중 검사 23 PASS. 기존 라우팅 스위트는 테스트 브리지에 `onOpenTool`이 없어 5 FAIL. 이번 커밋의 제품 변경은 CSS 세 파일로 한정했다.

비교 인덱스와 합성 캡처는 로컬 QA 저장소 `F:\BOGUNON_QA\INT_SWL04_20261125\index.html`에 둔다. Chromium 프로필은 저장소와 증거 공유에서 제외한다.
