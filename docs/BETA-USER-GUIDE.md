# BOGUNON DESK 0.1.0 공유 베타 사용자 가이드

## 1. BOGUNON DESK란?

BOGUNON DESK는 보건교사가 Windows에서 업무·일정과 로컬 업무 도구를 한 화면에 정리하는 데스크톱 워크스페이스입니다. 학생 건강기록을 저장하는 시스템은 아닙니다.

## 2. 설치

지원 환경은 Windows 10/11 x64입니다. 제공받은 `BOGUNON-DESK-0.1.0-Windows-x64-Setup.exe`를 실행합니다. 공유 베타는 아직 코드서명되지 않아 게시자 확인 또는 SmartScreen 경고가 표시될 수 있습니다. 보안 기능을 끄지 말고 제공자와 `SHA256SUMS.txt`의 체크섬을 확인하세요.

## 3. 첫 실행

첫 실행 안내는 최대 3단계입니다. 주요 기능을 확인하고, BOGUNON 계정은 연결하거나 `나중에 연결`을 선택할 수 있습니다. 마지막 개인정보 안내를 확인한 뒤 `시작하기`를 누릅니다. 설정의 `이 PC`에서 언제든 다시 볼 수 있습니다.

## 4. Google 계정 연결

설정의 `계정`에서 `Google로 연결`을 누르면 Windows 기본 브라우저에서 로그인합니다. BOGUNON과 같은 Google/Supabase 계정을 사용하며 앱의 embedded 화면에서 Google 비밀번호를 받지 않습니다. 계정 연결 없이도 로컬 도구는 사용할 수 있습니다.

## 5. 기본 화면

Workspace에는 달력, 오늘 업무, 우선 업무, D-Day, 주간 일정, 급식, 날씨 같은 위젯이 표시됩니다. BOGUNON 업무·일정 데이터는 계정을 연결해야 보입니다.

## 6. 화면 꾸미기와 Dock

우측 상단 `화면 꾸미기`에서 위젯 추가·숨김, 프리셋, 배경·카드 스타일, Dock 표시와 순서를 편집합니다. 기본 Dock은 자주 쓰는 최상위 실행 항목만 표시합니다.

## 7. 빠른 추가

`빠른 추가`에서 업무 또는 일정을 입력합니다. 사용자가 `저장`을 누르기 전에는 BOGUNON에 저장되지 않습니다. 로그아웃 상태에서는 로그인 안내가 표시됩니다.

## 8. 수행일과 마감일

업무의 `수행일`은 실제로 처리할 날짜이고, 선택적인 `마감일`은 제출·회신 같은 실제 기한입니다. 두 날짜는 같을 필요가 없으며 일정에는 마감일이 없습니다.

## 9. 업무 폴더

자주 쓰는 폴더를 최대 12개까지 이 PC에만 등록합니다. 폴더 경로는 계정 동기화에 포함되지 않으며 즐겨찾기를 삭제해도 실제 폴더나 파일은 삭제되지 않습니다.

## 10. 빠른 메모

현재 앱 실행 동안만 유지되는 임시 메모입니다. 앱을 완전히 종료하면 사라지므로 장기 보관 용도로 사용하지 마세요. 첫 줄을 Quick Add 업무 초안으로 보낼 수 있습니다.

## 11. 품의 도우미

XLSX/XLS/CSV와 텍스트형 PDF를 로컬에서 분석해 품목내역, 품의문, 구매결과를 준비합니다. 원본과 품목 데이터는 자동 업로드되지 않으며 현재 작업 중에만 유지됩니다.

## 12. 공문 작업실

새 공문 작성, 받은 공문 수정, 공문 핵심정리 mode를 제공합니다. 기본 초안과 AI 프롬프트는 AI 연결 없이 로컬에서 만들 수 있습니다. 작업 내용은 history나 cloud에 자동 저장되지 않습니다.

## 13. PDF/HWPX 가져오기

받은 공문 수정과 핵심정리에서 텍스트형 PDF 또는 HWPX 한 파일을 로컬로 읽습니다. 전체 경로는 UI에 표시하지 않고 filename만 보여줍니다.

## 14. BOGUNON 업무로 보내기

기본 핵심정리의 첫 action과 명확한 제출기한을 기존 Quick Add에 미리 채웁니다. 제출기한은 마감일로 들어가며 수행일은 오늘을 유지합니다. 원문·근거·담당자·파일명은 task에 포함되지 않고, 사용자가 확인 후 `저장`해야 실제로 등록됩니다.

## 15. AI 연결은 선택사항

설정의 `AI`에서 OpenAI 또는 Gemini와 model을 선택하고 본인의 API Key를 입력합니다. API Key는 앱 process memory에만 존재하며 앱을 완전히 종료하거나 재시작하면 사라집니다. 사용자가 직접 AI 작성/정리를 실행한 경우에만 선택 provider로 내용이 전송됩니다.

## 16. 개인정보와 저장 범위

- 계정 동기화: Workspace, appearance, Dock, launcher URL과 개인정보가 아닌 품의 template 설정
- 이 PC: 업무 폴더, 업무포털, onboarding 완료값, tray/autostart와 Windows 알림 설정
- 현재 실행 중에만: 빠른 메모, 공문/품의 작업 내용, AI Key와 연결 상태
- 학생 이름·학번·연락처·건강정보는 AI로 보내지 마세요.

## 17. 현재 지원하지 않는 기능

- legacy HWP 직접 가져오기
- 스캔 PDF 및 이미지 OCR
- 공문/품의 원본 자동 저장과 history
- 자동 업데이트 및 Microsoft Store 배포
- 학생 건강기록 저장

## 18. Tray와 앱 완전 종료

`창을 닫을 때 트레이로 최소화`가 켜져 있으면 창의 닫기 버튼은 앱을 Tray로 보냅니다. 앱을 완전히 종료하려면 Windows system tray의 BOGUNON DESK 메뉴에서 `종료`를 선택하세요. 완전 종료 시 빠른 메모와 AI Key 등 session-only 정보가 사라집니다.

## 19. 앱 제거와 남는 로컬 데이터

BOGUNON DESK를 제거하려면 **Windows 설정 → 앱 → 설치된 앱 → BOGUNON DESK → 제거**를 선택하세요. 앱을 제거하면 프로그램 실행 파일, 설치 폴더, 바로가기 등이 제거됩니다.

다만 `%LOCALAPPDATA%\kr.sungandi.schoolhealthdesk` 폴더에는 이 PC 전용 앱 설정과 로그인/session 관련 로컬 데이터 등이 남을 수 있습니다. 완전히 초기화하려면 다음 순서로 정리하세요.

1. BOGUNON DESK를 완전히 종료합니다.
2. Windows에서 앱을 제거합니다.
3. 필요한 데이터가 없는지 확인합니다.
4. `%LOCALAPPDATA%\kr.sungandi.schoolhealthdesk` 폴더를 직접 삭제합니다.

재설치 후 기존 로컬 설정을 유지하려면 해당 폴더를 삭제하지 않아도 됩니다.
