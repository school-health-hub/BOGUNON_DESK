## 구현 범위

- `문서·교육자료 > 교육영상 Finder`를 App Shell Main Workspace outlet에서 연다.
- App Rail 선택 상태와 상단 현재 위치 `문서·교육자료 / 교육영상 Finder`를 유지한다.
- 내부 뒤로 가기는 Finder를 닫고 `문서·교육자료` 목록으로 돌아간다.
- 기존 `educationVideoOpen`을 유일한 수명주기 owner로 유지했다. 별도 owner나 Finder 인스턴스를 추가하지 않았다.
- Home은 Finder 표시 중 숨김·비활성 상태이며, TD2 Home 지속 마운트와 Dock 저장 계약은 변경하지 않았다.

## Finder 수명주기·저장 계약

- Finder는 기존 `unmount-preserve-store` 계약을 유지한다.
- Rail/Home/내부 뒤로 이동하면 Finder renderer가 unmount되고 진행 중 검색 취소 cleanup이 실행된다.
- 재진입 시 검색 결과·선택 같은 renderer 임시 상태는 새로 시작한다.
- 네이티브 library의 저장 영상·안내문·사용자 메모·복구 안내는 기존 repository에서 다시 읽는다.
- 새 폐기 확인창, keep-alive, 자동 저장, 데이터 이전을 추가하지 않았다.

## 자동 복구 보호

- primary/backup JSON 형식, 격리 이름, 복구 엔진, 성공·실패 판정은 수정하지 않았다.
- primary 손상 격리, 정상 backup 복구, 양쪽 손상 실패, URL 검증·중복 방지 기존 테스트를 그대로 통과했다.
- Main, Preload, IPC, search vault, userData 경로는 변경하지 않았다.
