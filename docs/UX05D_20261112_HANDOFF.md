## 실제 owner와 수명주기

- `P0App.inventoryOpen`과 `inventoryMode`를 단일 owner로 유지했다.
- Inventory는 App Shell Main Workspace outlet에 한 인스턴스만 마운트된다.
- lifecycle registry의 `unmount-preserve-store` 계약을 유지한다.
- 뒤로 가기, Rail 이동, Home 이동은 기존 `InventoryWorkspace.leave()`를 통해서만 닫힌다.
- 편집기 또는 입고·사용·폐기 입력이 열려 있으면 기존 확인창을 사용한다. 새 확인 정책을 만들지 않았다.
- 취소하면 Inventory와 입력 상태를 유지하고, 승인하면 대상 카테고리로 이동한다.
- 재진입 시 transient 검색·필터·폼은 기존처럼 초기화되고, 저장된 로컬 JSON은 다시 로드된다.

## App Shell 통합

- 상위 위치: `물품·품의 / 물품관리`
- Rail 활성 상태: `물품·품의`
- 기존 대형 sibling WorkspaceShell을 제거하고 App Shell outlet에서 렌더링한다.
- Home은 기존 지속 마운트 상태를 유지하며 Inventory와 겹치지 않는다.
- synthetic preview와 로컬 모드 전환 owner는 그대로 유지했다.
- Inventory에서 Purchase Helper로 전달하는 값은 기존 session transfer이며 실제 재고를 변경하지 않는다.

## 저장·기능 계약

변경하지 않은 계약:

- 물품 생성·조회·수정·삭제
- 기본 단위, 권장 재고, 로트와 유효기간
- 입고·사용·폐기 및 수량 계산
- 검색과 상태 필터
- CAS revision 충돌 차단
- primary/backup, 원자적 저장, 오류 시 입력 보존
- 저장 후 재진입
- Purchase Helper 전달과 개인 Inventory 저장소 분리

현재 구현에 없는 category/sort/import/export/manual backup UI는 추가하지 않았다. Main, Preload, IPC, 스키마, JSON 형식도 변경하지 않았다.
