# IM-1A 마이그레이션 권위 원본 검토

## 세 출처

| 출처 | 확인된 역할 | 한계 |
|---|---|---|
| Google Sheets | 초기 규칙·필드·업무 관행 | 최신 운영본 여부 미확인 |
| BOGUNON Supabase | 실제 웹 코드의 저장/조회 경로 | 실제 DB 적용·최종 수정시각·운영 사용 여부 미확인 |
| 신규 Inventory | 목표 계약 | 아직 미구현 |

코드상 BOGUNON은 items/lots/receipts에 쓰지만 사용 차감이 없고 만료분도 현재고에 포함한다. 따라서 “코드가 DB를 쓴다”는 사실만으로 실제 현재 재고의 권위 원본이라고 결론낼 수 없다.

## 결정 게이트

사용자가 현재 어떤 화면/시트를 입고 및 사용 후 실제로 갱신하는지, 기준시각별 대조 결과, 마지막 수정 경로를 운영 책임자가 확인해야 한다. 전체 데이터 추출 없이 row count, max(updated_at), 비식별 집계 및 표본 승인 방식으로 검증한다.

## 이전 계약

1. 승인된 스냅샷과 기준시각, 출처를 기록한다.
2. item mapping과 중복·단위·날짜 exception report를 만든다.
3. 과거 이력이 없는 잔량은 `INITIAL_BALANCE` movement 한 건(필요시 lot별)으로 생성한다.
4. 기존 receipt와 초기잔액을 동시에 더하지 않는다.
5. 합성 데이터 dry-run, 비식별 집계 대조, 승인 후 실제 실행한다.
6. 전환 시 구형 쓰기를 중단하고 신규 원장만 쓴다.
7. 실패 시 신규 batch 전체를 롤백하거나 전환 전 스냅샷으로 복원하며, 구형 원본은 변경하지 않는다.

현재 권위 원본은 `DECISION REQUIRED`다.
