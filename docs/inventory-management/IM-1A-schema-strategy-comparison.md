## 권고: C 혼합형

기존 `medication_items`, 구매계획·입고 화면과 도메인 지식을 보존하되, 공유 재고의 권위 원장은 학교별 membership, stock lot balance, movement, request/idempotency, audit, purchase link를 신규 영역으로 구성한다. 기존 UUID를 바로 재사용할지는 데이터 대조 후 mapping table 또는 동일 ID 채택으로 결정한다.

기존 lot의 `quantity`는 원수량/잔량 의미가 불명확하고 직접 DML이 허용되므로 그대로 권위 원장으로 승격하지 않는다. 전환 기간에는 구형 UI를 read-only 또는 단일 쓰기 경로로 제한하고 이중 쓰기를 금지한다.

## 단계 경계

1. 신규 계약과 합성 DB에서 RLS/RPC 검증
2. 기존 item ID mapping 및 initial balance dry-run
3. 승인된 기준시각에 한 번만 초기잔액 생성
4. 신규 원장을 유일한 쓰기 권위로 전환
5. 대조 후 구형 쓰기 차단, 별도 승인 후 정리
