# IM-1B-4 취소 정책

원본은 삭제하지 않고 연결된 `REVERSAL` movement를 추가한다. `RECEIVE`, `USE`, `DISPOSE`, `ADJUST`만 취소 가능하며 원본이 해당 lot의 최신 movement이고 현재 잔량이 원본 직후 값과 일치해야 한다. 이미 취소된 원본과 음수 결과는 거부한다.

복원은 수량만 되돌린다. 만료·격리·사용불가 상태를 자동으로 `available`로 바꾸지 않는다. 따라서 폐기 취소 후 재사용 가능 여부는 별도 상태관리 계약이 필요하다. 이 제한 때문에 전체 업무정책 판정은 CONDITIONAL이다.
