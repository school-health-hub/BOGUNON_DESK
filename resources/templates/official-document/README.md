# home-v1 기본 서식

`home-v1.odt`는 저장소 소유자의 명시적 공개 포함 승인에 따라 기존 로컬 원본을 바이트 변경 없이 포함한 공문 기본 서식이다.

- SHA-256: `8BC0FD240B1BEA06758794D9F07A75ABF7FAF13BAC1FBDBCDD3556BE3FF6C285`
- 크기: 10,712 bytes
- 기존 home-v1 계약: 북마크 43개, 표 4개, 프레임 4개, 스타일 참조 255개.
- ZIP 6개 항목의 XML 본문·메타데이터를 검사했다. 작성자 필드는 비어 있고 내용은 기본 서식 문구다. 학생/교직원/학교 식별정보, 숨은 본문, 변경 추적, 외부 파일 링크는 발견되지 않았다. 생성/인쇄 날짜 메타데이터는 원형 유지했다.
- 이는 개인정보에 대한 정적 점검 결과이며 별도 제3자 저작권 감사 완료를 의미하지 않는다. 기존 저장소 전체에 새로운 라이선스를 적용하지 않는다.

Rust `include_bytes!`로 실행본에 포함되므로 설치 폴더의 외부 파일이나 인터넷이 필요하지 않다. 저장 시에도 기존 SHA/북마크/ZIP/표/프레임/스타일 검증을 통과해야 한다. 기존 승인 서식은 수동 선택으로 계속 지원한다. 임의 수정본을 자동 승인하지 않는다.

합성 테스트 문구는 이 원본에 추가하지 않았다. 원본 파일은 수정하거나 정제하지 않았다.
