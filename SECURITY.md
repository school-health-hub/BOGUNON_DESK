# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities, credentials, personal information, or school data in public issues.

Use GitHub's private vulnerability reporting / Security Advisory flow for this repository when available. Include only the minimum information needed to reproduce the issue, and redact real student, staff, school, account, API key, token, and document data.

## Supported versions

Security fixes are applied to the current release line of BOGUNON DESK. Users should update to the latest available version before reporting an issue that may already be fixed.

## Data handling

BOGUNON DESK is designed so that local document contents and user-provided credentials are not committed to the source repository. Do not add real operational data, secrets, or exported user files to issues, pull requests, fixtures, screenshots, or test assets.
