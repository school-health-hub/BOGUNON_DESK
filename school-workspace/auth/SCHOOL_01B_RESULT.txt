3. Electron Main Auth adapter 구현

Renderer status는 Auth UUID와 만료시간만, 오류는 고정 코드만 반환한다.

구현:
- beginSignIn: 이전 흐름/공동 메모리/저장 세션 정리, 공식 provider.start,
  허용된 HTTPS Auth authorize URL만 시스템 브라우저 port로 전달
- handleCallback: 고정 protocol/host/port/path, 중복·알 수 없는 query/fragment/

  동기적 일회 소비, 로그아웃/계정 전환 중 늦은 완료 폐기
- restore: 암호화 세션 검증·유효 세션 재사용·만료 임박 refresh, 사용자 UUID
  불일치/손상/저장 실패시 공동 상태만 오류/재로그인으로 전환
- logout: 요청 세대·공동 캐시 무효화, 파일 삭제, 공식 local signOut 요청.
  원격 실패는 unconfirmed, 로컬 삭제 실패는 STORAGE_UNAVAILABLE로 보고
- WindowsSessionVault: Windows+isEncryptionAvailable를 만족할 때만 encryptString.
  평문 fallback 없음. 저장 중 부분 실패도 clear를 시도한 뒤 오류 처리
- FileSessionBlob: 전용 school-workspace-auth-v1/session.bin, 제한 크기,
  symlink/hardlink 거부, 0600 임시파일·sync·원자적 rename. Finance/AI/Tauri
  저장 파일·암호화 key를 읽거나 재사용하지 않음

4. Web BFF Auth adapter 구현
WebBffAuthAdapter는 동일 provider user UUID를 그대로 사용한다. 이메일·실명·
로컬 학교값으로 계정을 합치거나 역할을 부여하지 않는다.

구현:
- 무작위 256bit session handle, 서버 hash key, Auth access/refresh token은 서버만
  보관. 브라우저에는 __Host-ws_session opaque cookie와 CSRF proof만 전달
- cookie: HttpOnly; Secure; SameSite=Lax; Path=/; Domain 없음. 세션 TTL 12시간,
  pre-auth flow cookie 5분. 초기 로그인/계정 전환 때 handle 재발급
- 기존 세션의 요청은 POST+정확한 Origin+CSRF 검증. 초기 begin은 정확한 Origin,
  OAuth GET callback은 HttpOnly flow binding+state로 로그인 CSRF/재사용 차단
- 서버 refresh token 보관 store 인터페이스. 메모리 구현은 testOnly이며
  production 모드로 사용하면 구성 오류. 실제 호스트/영속 store는 미선정/미구현
- refresh는 store의 per-session shared lock으로 직렬화, 회전 결과는 CAS 저장.
  logout이 먼저 revoke하면 늦은 refresh는 새 세션을 복원할 수 없음
- Workspace generation을 store record에 유지. 다른 BFF 인스턴스에서 학교를
  바꿔도 이전 성공·실패 응답 폐기. 로컬 AbortSignal도 함께 사용
- 계정 전환/로그아웃/만료/인가 거부시 공동 context 초기화. 테스트는 두 adapter
  인스턴스+동일 store의 경쟁 상태도 포함

production store는 암호화 at rest, 공유 CAS/lock·원격 해지의 원자성이 필요하다.
OAuth pending-flow map은 현재 프로세스 메모리이므로 멀티 인스턴스 운영에서
durable/shared flow 저장소 또는 명시적 routing 설계도 추가 검토해야 한다.
실제 HTTP route/호스팅/CORS 정책/네트워크 timeout·요청 제한은 후속 통합 항목이다.
호출 route는 req.origin을 body값이 아닌 실제 HTTP Origin header에서 전달해야 한다.
서버 세션 key나 refresh token을 public 테이블/Renderer에 저장하는 경로는 없다.
